1//! Lifted STARK prover and verifier (LMCS-based).
2//!
3//! This crate implements the lifted STARK protocol combining LMCS (Lifted Matrix
4//! Commitment Scheme), DEEP quotient construction, and FRI for low-degree testing.
5//!
6//! # AIR Trust Model
7//!
8//! The lifted STARK has three trust domains:
9//!
10//! 1. **AIR = trusted** — [`air::LiftedAir`] implementations are correct application code. It is
11//!    the AIR implementer's responsibility to satisfy the contract below.
12//!    [`air::LiftedAir::validate`] checks the statically-verifiable subset.
13//!
14//! 2. **Instance = validated** — The prover validates that its witness matches the AIR spec. The
15//!    verifier validates instance metadata. Both return structured errors.
16//!
17//! 3. **Proof = untrusted** — Transcript data is verified cryptographically (PCS errors, constraint
18//!    mismatch, etc.).
19//!
20//! ## Validated properties
21//!
22//! These are checked by [`air::LiftedAir::validate`] and by the internal
23//! instance validator in [`instance`], and enforced by both prover and
24//! verifier before proceeding:
25//!
26//! - **No preprocessed trace** — the lifted protocol does not support them.
27//! - **Positive aux width** — every AIR must have an auxiliary trace.
28//! - **Periodic columns** — each has positive, power-of-two length ≤ trace height.
29//! - **Constraint degree** — `log_quotient_degree() ≤ log_blowup`.
30//! - **Instance dimensions** — trace width, public values length, var-len public inputs count, and
31//!   trace height (power of two) all match the AIR specification.
32//!
33//! ## Unchecked trust assumptions
34//!
35//! These cannot be verified statically and are the AIR implementer's responsibility:
36//!
37//! 1. **Window size** — Only transition window size 2.
38//! 2. **Deterministic constraints** — `eval()` emits the same number and types of constraints
39//!    regardless of builder implementation.
40//! 3. **Consistent aux builder** — `AuxBuilder::build_aux_trace` returns width = `aux_width()`,
41//!    height = main trace height, and exactly `num_aux_values()` values. (The prover asserts these
42//!    at runtime as a defense-in-depth sanity check.)
43//! 4. **Sound `reduced_aux_values`** — Returns correct bus contributions for valid inputs.
