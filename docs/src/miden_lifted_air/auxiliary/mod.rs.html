1//! Auxiliary trace types: builder and cross-AIR identity checking.
2//!
3//! # Protocol Overview
4//!
5//! The auxiliary trace enables cross-AIR buses (multiset / logup) in the lifted STARK.
6//!
7//! ## Prover
8//!
9//! 1. [`AuxBuilder::build_aux_trace`] constructs the aux trace and returns aux values
10//!    (extension-field elements whose meaning is AIR-defined).
11//! 2. The aux trace is committed (Merkle commitment).
12//! 3. Aux values are sent via the Fiat-Shamir transcript.
13//!
14//! ## AIR constraints ([`eval`](crate::LiftedAir::eval))
15//!
16//! 4. The AIR defines how aux values relate to the committed aux trace. A common pattern is to
17//!    constrain them to equal the aux trace's last row, but the protocol does not impose this — the
18//!    AIR is free to define whatever relationship it needs.
19//! 5. Transition constraints enforce the aux trace's internal logic (e.g. running product
20//!    accumulation).
21//!
22//! ## Verifier
23//!
24//! 6. The verifier receives aux values from the transcript.
25//! 7. Constraint evaluation (steps 4–5) is checked at a random point.
26//! 8. [`reduced_aux_values`](crate::LiftedAir::reduced_aux_values) computes each AIR's bus
27//!    contribution from the aux values, challenges, and public inputs.
28//! 9. Global check: all contributions combine to identity (prod=1, sum=0).
29

36/// Variable-length public inputs for an AIR instance.
37///
38/// A list of *reducible inputs*: each `&[F]` is a slice of base-field elements
39/// that [`LiftedAir::reduced_aux_values`](crate::LiftedAir::reduced_aux_values)
40/// reduces to a single extension-field value. The AIR defines how to group and
41/// interpret them (e.g. which inputs belong to which bus).
42///
43/// The number of slices must equal
44/// [`LiftedAir::num_var_len_public_inputs`](crate::LiftedAir::num_var_len_public_inputs).
45///
46/// **Commitment:** callers **must** bind these inputs to the Fiat-Shamir
47/// challenger state, just like the AIR's public values.
48pub type VarLenPublicInputs<'a, F> = &'a [&'a [F]];
