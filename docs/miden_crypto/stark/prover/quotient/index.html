Quotient polynomial helpers used by the prover’s per-AIR pipeline.

  • upsample_evals: Low-degree extend coset evaluations onto a larger two-adic coset (the constraint-degree axis: D_j -> D_max, same polynomial, denser evaluations).
  • cyclic_extend_and_accumulate: Lift the running accumulator along the trace-height axis (n_j -> N) by cyclic repetition, and Horner-fold a new AIR’s contribution in via beta.
  • commit_quotient: Decompose Q(gJ) into chunks and commit on gK.
