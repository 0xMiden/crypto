Divide quotient numerator by vanishing polynomial in-place (natural order).

Replaces each numerator[i] with numerator[i] / Z_H(xᵢ) where Z_H(X) = Xᴺ − 1 and N is the trace height.

This uses a periodicity trick: on the quotient evaluation coset gJ of size N·D, the values Z_H(x) take only D distinct values, so we can batch-invert those D values once and reuse them by modular indexing.

Note that here coset.log_blowup() is log2(D) because coset is the quotient domain (blowup = constraint degree), not the PCS/FRI blowup B.
