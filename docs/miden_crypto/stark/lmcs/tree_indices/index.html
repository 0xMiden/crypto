Module tree_indices

Validated Merkle tree leaf indices and missing sibling iteration.

TreeIndices bundles a sorted, deduplicated set of leaf indices with the tree depth, enforcing the invariant that every index is in 0..2^depth.

MissingSiblingsIter walks the tree upward from a set of leaf positions and yields the sibling nodes absent from the set — exactly the nodes whose hashes must be provided to reconstruct the root.
