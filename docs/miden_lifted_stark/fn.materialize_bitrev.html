Materialize a matrix into domain-ordered BitReversedMatrixView<RowMajorMatrix<T>>.

Temporary adapter for types that implement the upstream [p3_matrix::bitrev::BitReversibleMatrix] but not this crate’s local copy. The returned type implements both traits and can be passed directly to Lmcs::build_tree / Lmcs::build_aligned_tree.

Remove alongside BitReversibleMatrix when upstream impls cover all DFT output types.
