Module poseidon2

Wraps Plonky3’s [Poseidon2Air] as a LiftedAir.

Uses the standard Goldilocks configuration: WIDTH=12, SBOX_DEGREE=7, SBOX_REGISTERS=1, HALF_FULL_ROUNDS=4, PARTIAL_ROUNDS=22.
