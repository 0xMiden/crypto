Expand description

Generate benchmark matrices from relative specs.

Creates matrices with heights relative to max_height = 1 << log_max_height. Each spec (offset, width) creates a matrix with:

  • height = max_height >> offset
  • width = width

Matrices in each group are sorted by ascending height.
