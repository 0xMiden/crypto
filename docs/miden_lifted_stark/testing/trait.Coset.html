Expand description

Shared interface for two-adic coset-like multiplicative domains.

A coset s · H is parameterised by:

  • log_size: log₂ of the order |H|,
  • shift: the multiplicative offset s ∈ F (F::ONE for a plain subgroup),
  • generator: a primitive 2^log_size-th root of unity.

Implemented by TwoAdicSubgroup (with shift = F::ONE) and TwoAdicCoset. The default bodies for point_at, points, bit_reversed_points, vanishing_at, contains, size, and generator_inverse are written once here in terms of the three required methods — for a subgroup, the shift collapses to F::ONE and the formulas reduce to the unshifted case.

LiftedDomain deliberately does not implement this trait: it composes a trace subgroup and an LDE coset, each with its own vanishing polynomial, and exposing a single Coset interface would force one to silently win. Callers reach into the parts: domain.trace_subgroup() or domain.lde_coset().

Provided Methods§

Source

fn shift_inverse(&self) -> F

Cached inverse of Self::shift. The default body recomputes it on every call; implementations should override either with a free constant (F::ONE for a subgroup) or by returning a value computed once at construction time. vanishing_at and contains route through this method so multiple invocations on the same coset don’t redo the inversion.

Source

fn size(&self) -> usize

Domain order: 2^log_size.

Source

fn generator_inverse(&self) -> F

Inverse of the generator. Convenient for FRI twiddle factors and last-row Lagrange denominators.

Source

fn point_at(&self, i: u64) -> F

The i-th point in natural order: s · ωⁱ.

Source

fn points(&self) -> Vec<F>

All points in natural order, length 2^log_size.

Single-pass iteration via shifted_powers(self.shift()): produces s, s·ω, s·ω², … directly without an intermediate “unshifted then map” step.

Source

fn bit_reversed_points(&self) -> Vec<F>

All points in bit-reversed order.

Source

fn vanishing_at<EF: ExtensionField<F>>(&self, z: EF) -> EF

Vanishing polynomial of the domain at z: (z/s)^|H| − 1.

For a subgroup (s = 1) this reduces to z^|H| − 1.

Source

fn contains<EF: ExtensionField<F>>(&self, z: EF) -> bool

Membership test: returns true iff (z/s)^|H| == 1.
