Field/hash configuration modules for testing.

Each module provides complete type aliases, constructors, and helpers for testing at any level (LMCS, PCS, or full STARK).

The common field types (Felt, QuadFelt, PackedFelt) are defined here and re-exported by each hash configuration module.
