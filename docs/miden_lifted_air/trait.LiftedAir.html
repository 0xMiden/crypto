Expand description

Super-trait for AIR definitions used by the lifted STARK prover/verifier.

Inherits from upstream traits for width and public values. Adds Miden-specific auxiliary trace support and periodic column data. Every LiftedAir must provide an auxiliary trace (even if it is a minimal 1-column dummy).

§Type Parameters

  • F: Base field
  • EF: Extension field (for aux trace challenges and aux values)

fn num_aux_values(&self) -> usize

Number of extension-field aux values committed to the Fiat-Shamir transcript.

Returned by build_aux_trace alongside the aux trace matrix; the count is independent of aux_width (the number of aux trace columns). Exposed to constraints as permutation values via PermutationAirBuilder::permutation_values.

Build this AIR’s auxiliary trace and aux values.

challenges contains exactly num_randomness extension-field elements for this AIR. The returned aux_trace has width aux_width and the same height as main; aux_values has length num_aux_values.

fn max_periodic_length(&self) -> usize

Maximum periodic-column length, or 0 if there are none. A trace’s height must be at least this, so it is the per-AIR lower bound on trace height.

The default derives it from periodic_columns, asserting each column is a non-empty power of two. Override to return it directly when known statically; the override is cross-checked by crate::debug::assert_multi_air_valid.

Source

fn air_layout(&self) -> AirLayout

Return the AirLayout describing this AIR’s dimensions.

This is the single source of truth for building symbolic or layout builders.

Source

fn constraint_degree(&self) -> ConstraintDegrees
where Self: Sized,

Symbolic constraint degree multiples, split into base-field and extension-field maxima (see ConstraintDegrees).

The split lets callers report base and extension constraint degree maxima separately; STARK prover/verifier code derives quotient degrees from these raw symbolic bounds later. Override this when the split is known statically so a per-AIR bound can be sharp without redoing the symbolic pass.
